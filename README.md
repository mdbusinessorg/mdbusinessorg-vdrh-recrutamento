# VDRH Recrutamento

Plataforma de recrutamento premium para a VDRH — Visão e Desenvolvimento de Recursos Humanos.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Lucide React

## Funcionalidades

- Landing page moderna e responsiva
- Listagem de vagas com filtros por tipo e localização
- Página de detalhe de vaga com formulário de candidatura
- Design dark/light
- Dados da VDRH (equipa, serviços, valores, contactos)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O output estático é gerado em `dist/`.

## Deploy

Pode ser deployado na Vercel, Netlify ou qualquer CDN estática.
